Base model

The model is the base serial the app reads out of the advertisement. Switching it ends the activation, so the phone activates a fresh patch.

Base serial

Type this exact string in the app when it asks for the base serial: 4A12D828 is a 200U base (MD0201), 52DF1614 a 300U base (MD8301). The advertisement carries it reversed (28 D8 12 4A), which is the form the app matches on; the string above stays the one you type. A serial the app cannot derive a model from is refused here.

Reservoir

Patch state

A real patch moves through priming and activation on its own; here you can drop it into any state to see how the app reacts.

Fault

A faulted patch stops delivery and must be replaced.

Unacknowledged command

The ESP32 reboots at the next command, leaving the phone without a response, then comes back as the same base. Watch how the app recovers.

New patch

Clears the activation and delivery: the next phone activates a fresh patch on the same base. Deactivating the patch from the app does the same.

Failure injection

One BLE link is shared by all three simulators, so drop and refuse act on the next connection whichever device asked; quiet removes only this device from advertising; delay holds each outgoing notification; ignore drops that many messages from the phone, then resumes.
