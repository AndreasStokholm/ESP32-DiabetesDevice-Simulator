ESP-Sim flasher

Turn an ESP32-S3 into an Omnipod pod simulator (DASH or Omnipod 5) and a Dexcom G7 sensor simulator, for testing Loop, Trio and similar apps. Flash it from this page; nothing to install.

Test equipment only

This is not a Dexcom or Insulet product and not a medical device. It delivers no insulin and every value it reports is made up. Never use it, or an app paired to it, for anyone's therapy. Pair it only from a test phone.

You need

  • An ESP32-S3 board with at least 8 MB of flash
  • A USB data cable (some cables only charge)
  • Chrome or Edge on a computer. Safari, Firefox and phones can't flash.

Steps

  1. Plug the board into the computer and press Connect and install.
  2. Pick the board's port. It is usually listed as USB JTAG/serial debug unit.
  3. Choose Install. Tick Erase device for a fresh start; leave it unticked to update a board and keep its paired sensor and pod.
  4. When it finishes, close the installer and press Show my board's details above. It shows the G7's name and 4-digit pairing code, the pod type, and the board's Wi‑Fi name and password.
  5. In the app, pair an Omnipod DASH pod and add a Dexcom G7 with that code.

If it doesn't work

  • No port listed: try another cable or USB port. If the board has two USB sockets, use the one marked USB, not UART or COM.
  • Stuck on "Preparing installation", or it won't connect: the board hasn't entered download mode. Close the dialog, hold the board's BOOT button, tap RESET, release BOOT, then reload this page and try again. After installing, press RESET once to start the firmware.
  • Nothing after installing: press RESET, or unplug the board and plug it back in.
  • The console accepts commands. Type help for the list, status for the pairing code.
